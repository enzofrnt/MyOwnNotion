bounded defects. Partial database projection merging appended local rows that

identities between checks. PR175 includes these corrections and passed its PR

## A44 — MCP refused credentials absent from the security audit

The MCP exchange and bearer paths safely refused invalid, consumed, expired and
revoked credentials, but the refusal was only translated into the HTTP response.
No `security_audit_events` row existed for the attempt, leaving connection
abuse and repeated authentication failures invisible to the owner despite the
product canvas section 35 requirement.

013 T022 adds RED/GREEN real HTTP coverage for invalid, consumed, expired and
revoked exchange codes and invalid, expired and revoked bearer credentials.
The access service records fixed `mcp.exchange-failed` and
`mcp.authentication-failed` events through the canonical `AuditService` and
