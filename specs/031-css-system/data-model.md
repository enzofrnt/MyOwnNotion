# Modèle de styles

Aucun modèle persisté modifié.

- Token sémantique : nom stable, rôle, valeur claire/sombre, aliases de compatibilité.
- Propriétaire : feuille chargée, domaine, consommateurs, exceptions documentées.
- Composition : primitives réelles, disposition, états, source et référence visuelle.
- Preuve : surface, thème, viewport, scénario, mesures/capture et limite de validation.

Variables dynamiques (géométrie, contenu, Shiki, Ariakit) restent locales ; elles
ne sont pas des décisions de thème et ne doivent pas devenir des tokens globaux.
