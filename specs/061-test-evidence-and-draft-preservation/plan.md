## Architecture

**Product** (`apps/web/src/features/databases/table-view.tsx`): the draft of the
inline property composer is component state. It now survives an implicit close —
outside press, re-render, scroll — and is cleared only when the composer is used
(a property created) or explicitly abandoned (`Escape`). The open handler no
longer resets it.

**Guidance** (the durable part):

| Home | Content | Why there |
| --- | --- | --- |
| `.specify/memory/constitution.md` (art. III) | the non-negotiable obligation | the highest authority an agent reads first |
| `.agents/skills/test-quality/SKILL.md` | when to load, Speckit gates, checklist, escalation path | a maintained skill next to `ui-quality`, discoverable in the skill catalogue and referenced by `AGENTS.md` |
| `.agents/skills/test-quality/lessons.md` | append-only journal `L-NNN` (symptom, anti-pattern, rule, proof) | the journal must be loaded, so it lives in the skill folder |
| `docs/testing/wait-contracts.md` | the normative witness catalogue | already referenced by `docs/development.md`; now points at the skill |
| `AGENTS.md` | required workflow: load the skill for any test work | the file agents open first in the repository |

Rejected: a lessons file under `docs/` (not read by the workflow), and a

## Test strategy

| Level | What it proves | Why this level |
| --- | --- | --- |
| Component test (`apps/web/tests/database-new-property-draft.spec.tsx`) | the three draft semantics: outside press keeps, creation clears, `Escape` clears | deterministic, no pointer geometry, fails without the fix |
| Two journeys (`databases-tasks`, `database-form-lifecycle`) | the real flow: a cancelled press creates nothing and loses nothing | end-to-end coverage of the gesture; they restore the composer first so the outcome cannot depend on where a press landed (lessons L-001) |

No new sleep, no retry, no weakened assertion: the assertion on the draft is
unchanged, and it now protects a guarantee the product holds. Deliberate
interruption coverage from feature 060 is untouched.
