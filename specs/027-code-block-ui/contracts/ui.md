# UI contract

Code block region: « Bloc de code ». Language select: « Langage du code »,
showing human-readable supported language names, « Texte brut » for empty/text,
and an extra option preserving an unknown saved language. Disabled read-only.
Copy button: « Copier », semantic click activation. Source is the existing plain
editable contentDOM; HTML remains literal. Status reports copied/failed locally.
Clipboard refusal retains the source and allows retry. Horizontal scrolling is
inside `pre`; all theme token decoration styles stay outside canonical content.
