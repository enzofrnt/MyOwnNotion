# Editor contract

/équation et /sommaire insèrent au curseur ; les requêtes du slash sont retirées
avant transformation du bloc. Une source invalide reste éditable et durable.
Les deux sommaires ciblent les IDs dans le bon host ; les toggles ancêtres sont
ouverts. Les portals inactifs disparaissent. ListView conserve propriétés et
ordre, masque les noms répétitifs visuellement. L'import028 convertit les
équations/TOC nativement et conserve les frontières des équations inline.
