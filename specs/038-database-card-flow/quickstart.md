# Manual validation

Sur 8082 isolé, ouvrir Suivi des tâches. Crayon/menu dans une capsule commune.
Modifier une fixture : titre, case, date, choix de propriété ; vérifier autosave
sans boutons puis recharger. Le menu de propriété garde l'édition ouverte ; clic
extérieur ferme. Changer l'axe : carte stable pendant édition, destination réelle
après fermeture. Page/Dossier toujours visible ; page vide conversion immédiate,
page avec contenu confirmation explicite, annulation conserve le contenu.

Créer une carte : type/propriétés avant Entrée ou clic extérieur ; pas d'ouverture
et pas de brouillon vide accidentel. Échap ferme le brouillon vide. Vérifier refus,
reprise et anti-double. Menu : icône, volet, pleine page, copie, conversion et
corbeille. Comparer l'icône de conversion dans l'arbre. Revoir clair/sombre,
320 px, keyboard/focus et animations réduites. Ne retirer que les fixtures de
cette revue, puis contrôler les comptes de colonnes inchangés.

Réglages de vue → Grouper : vérifier la propriété affichée et le panneau
Grouper par, choisir Matière puis recharger. Revenir à État sans modifier les
cartes, les filtres, tris ou propriétés visibles. Le panneau Trier ne propose
plus de regroupement et aucun bouton ne reste au-dessus du Kanban. Vérifier
le même accès depuis une base intégrée, Échap du sélecteur, retour du focus
après sauvegarde, clair/sombre et 320 px. Les propriétés retirées/incompatibles
ne sont pas proposées ; un refus conserve le choix pour Réessayer.
