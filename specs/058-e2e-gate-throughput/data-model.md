# Data Model: E2E Gate Throughput and Fast Failure

No product data. The entities below are CI planning and evidence records.

## Impact policy (`ci/test-impact.json`)

| Field | Type | Rule |
| --- | --- | --- |
| `e2eProjects` | string[] | unchanged; unique; `none` reserved |
| `e2eLanes.targetSeconds` | integer | NEW; 120–3600; desired journey time per lane |
| `e2eLanes.maxPerProject` | integer | NEW; 1–12 |
| `e2eLanes.defaultSecondsPerTest` | number | NEW; > 0; used when no timing exists for a file |

## Timings (`e2e-timings.json`, optional planner input, generated)

`{ version: 1, projects: { <project>: { <spec file>: seconds } } }`. Unknown
projects/files are ignored; missing entries fall back to the static estimate.

## Impact plan (`test-impact.json`, generated)

`e2e.lanes[]`:

| Field | Type | Rule |
| --- | --- | --- |
| `id` | string | `<project>-<index>-<total>`; artifact-safe |
| `project` | string | one of `e2eProjects` |
| `index`, `total` | integer | `1 ≤ index ≤ total ≤ min(maxPerProject, selected files)` |
| `testFiles` | string[] | non-empty, sorted, subset of `e2e.testFiles` |
| `estimatedSeconds` | number | sum of the weights of `testFiles` |

`e2e.matrix[]` entry: `{ project, lane: "<index>/<total>", laneId }`, one per
lane, in project then index order.

Invariants: per project, lanes partition `e2e.testFiles` (union equal, pairwise
disjoint); `total = clamp(ceil(Σ weights / targetSeconds), 1, min(maxPerProject,
files))`; the same inputs always produce the same plan; mode `none` yields no
lane and the single matrix entry `{ none, 1/1, none }`.

## Lane

One matrix entry at run time. Owns: runner, PostgreSQL, API, preview, blob
root, deployment key, browser process. Produces `blob-report-<laneId>`
and failure evidence. States: `queued → running → success | failure | cancelled | timed-out`.

## Gate summary (`e2e-gate-summary.json`, generated by `e2e-report`)

| Field | Type |
| --- | --- |
| `candidateSha`, `event`, `mode` | string |
| `projects[]` | `{ project, selected, passed, failed, flaky, skipped, notRun, failedAttemptSeconds }` |
| `lanes[]` | `{ laneId, project, present, estimatedSeconds, durationSeconds, interruptedByMaxFailures }` |
| `slowest[]` | up to 10 `{ project, file, title, seconds }` |
| `verdict` | `pass` \| `fail` |
| `reasons[]` | string, non-empty when `fail` |

Verdict rules are normative in [contracts/gate-rules.md](./contracts/gate-rules.md).
