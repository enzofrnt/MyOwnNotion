# Data model

Modèle existant inchangé : multi-select.optionIds contient les identités d'options ; row.entryId désigne une seule entrée. EvaluatedDatabaseGroup.entryIds contient ses membres ; plusieurs groupes peuvent référencer la même entrée. totalCount reste le cardinal des entrées filtrées. Options actives ordonnées ; retired conservées, non rendues. Un déplacement produit une unique propriété typée via commande canonique sous révision ; aucune nouvelle entité.
