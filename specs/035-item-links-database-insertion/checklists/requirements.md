# Specification quality checklist

- [x] Besoin et limites définis sans choix technique dans les exigences.
- [x] Canevas, dépendances et distinction lien/hiérarchie/source précisés.
- [x] Trois stories indépendantes avec scénarios et critères vérifiables.
- [x] Annulation, retry, données privées et éditions locales explicités.
- [x] UI : clavier, focus, états, thèmes et 320px requis.
- [x] Hypothèses raisonnables documentées ; aucune ambiguïté bloquante.
